# GRØD Names Helper

A small free app that lets [GRØD](https://gaspery.com/grod) suggest the names of
the people in your Microsoft Teams calls.

**[Download the latest release](https://github.com/holleyy/grod-names-helper/releases/latest)** ·
[How it works](https://gaspery.com/grod/names-helper)

## What it reads

While GRØD records a Teams call, the helper reads the name on each participant
tile, which tile Teams highlights as speaking, and when. When the recording
stops, GRØD lines those moments up with the voices it heard and suggests a name
for each voice. One click names a voice.

It never reads chat, captions, shared screens, meeting notes, or anything anyone
types or says, and it never clicks or types in Teams. It keeps names and times
in a folder it shares only with GRØD, on your Mac, and it has no networking code.

## What you need

- macOS 27 or later
- The new Microsoft Teams app
- A version of GRØD with Names from Teams

Each release is signed by Gaspery Limited and notarised by Apple. This
repository holds releases only.
